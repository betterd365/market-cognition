## 引言

> 用 AI 做一部漫剧，听起来像科幻。但如果把每个环节拆开看——写剧本、画角色、做分镜、驱动视频——这些都是 AI 已经在做的事。

我们真正缺的不是能力，而是把这些能力串成一条**不需要人盯着的自动化管线**。

本文记录了团队对 AI 漫剧全流程管线的规划设计。从脑暴到成片，我们设计了三个阶段、六个审批节点、三条并行通道。这是一份还在施工中的蓝图，但已经足够分享。

---

## 管线全景：三段式架构

```
Phase 1: 创意孵化 (n8n 驱动)
  ├─ A1. 市场调研 → 赛道分析报告
  ├─ A2. 选题确认 → 审批点①: 老板选方向
  └─ A3. 剧本生成 → 完整剧本 + 角色列表
       └─ 审批点②: 老板审剧本

Phase 2: 视觉预产 (ComfyUI 本地)
  ├─ B1. 角色设计 → 每个角色三视图
  │    └─ 审批点③: 确认角色形象一致性
  ├─ B2. 分镜脚本 → 逐镜脚本 JSON
  │    └─ 审批点④: 确认节奏和视觉风格
  └─ B3. 逐镜出图 → 每镜关键帧 PNG
       └─ 审批点⑤: 确认构图和叙事

Phase 3: 视频生成 (Seedance 2.0 云端)
  ├─ C1. 逐镜驱动视频 → mp4 片段
  ├─ C2. FFmpeg 拼接 → 完整视频
  ├─ C3. TTS 配音 → 音轨
  └─ C4. 合成交付 → 视频+音轨+字幕
       └─ 审批点⑥: 老板最终审片
```

三个阶段，职责清晰：

- **Phase 1** 是创意的大脑——调研、选题、剧本。用 n8n webhook 串联 LLM 调用，自动化执行，人工只在两个审批点介入。
- **Phase 2** 是视觉的骨架——角色、分镜、关键帧。在本地 ComfyUI 上跑图，成本为零（除了电费和显卡损耗）。100 张图出错了重跑就是，不用花钱。
- **Phase 3** 是花钱的步骤——调用 Seedance 2.0 云端 API 驱动视频，前面所有审批必须全绿才能触发。

## 为什么是「审批驱动」而非「全自动」

你可能会问：既然每个环节都能用 AI 自动跑，为什么还要插 6 个审批点？

答案是：**AI 可以写完一部剧，但不能审完一部剧。**

漫剧的出品不是生成就完事了。角色今天和明天长得不一样，分镜节奏拖沓，关键帧构图奇怪——这些问题是 AI 自己发现不了的。审批节点的设计，本质是把「创意判断」交给人，「重复劳动」交给机器。

| 编号 | 节点 | 审批内容 | 对应用例 |
|------|------|----------|----------|
| ① | A1→A2 | 赛道报告 → 选题方向 | 做修仙还是赛博？老板拍板 |
| ② | A2→A3 | 完整剧本 | 逻辑漏洞、人物弧光够不够 |
| ③ | B1 | 角色三视图 | 男主今天和明天长得一样吗 |
| ④ | B2 | 分镜脚本 | 节奏对不对，视觉风格统不统一 |
| ⑤ | B3→C1 | 关键帧预览 | 构图和叙事确认，放行进视频 |
| ⑥ | C4 | 成片 | 最终审片，修改意见 |

审批通过 → 自动进入下一步。这是「半自动」的精髓。

## 三处并行机会

传统动画制作是串行的——做完角色再做分镜，做完分镜再画关键帧。但 AI 管线有三个有意思的并行点：

**1. 调研 + 角色设计可并行。** A1（市场调研）和 B1（角色设计）没有依赖关系。调研在跑的时候，角色图可以提前生成——只差 IPAdapter 的一致性锁定。

**2. 多角色可并行出图。** B1 中，5 个角色的三视图可以同时跑不同 seed，ComfyUI 的队列机制天然支持。

**3. 多镜号可并行出关键帧。** B3 中，15-30 镜的关键帧可以批量提交。唯一的限制是 Seedance API 的并发排队。

实际压缩效果：如果串行需要 8 小时，加入这三处并行大约 4-5 小时可以跑完一条完整管线。

## 技术栈选型

| 组件 | 工具 | 选择理由 |
|------|------|----------|
| 工作流引擎 | **n8n** | Webhook 天然支持「触发 → 调用 LLM → 输出」的链式逻辑，适合非开发者编排 |
| 图像生成 | **ComfyUI** | 节点式工作流，支持 IPAdapter 角色一致性锁定，本地跑零 API 费用 |
| 基础模型 | **animagine-xl-4.0** | 动漫风格专精，比通用 SDXL 更适配漫剧场景 |
| 视频生成 | **Seedance 2.0** | I2V（图生视频）200 帧支持，限流已解除 |
| 拼接合成 | **FFmpeg** | 老牌可靠，视频片段拼接 + 音轨合成一条命令搞定 |

## 一个观察

这条管线最有趣的设计不是技术栈——n8n + ComfyUI + Seedance 的组合并不新颖。

**有趣的是「审批驱动」的模式。**

在 AI 能自动生成一切的当下，故意插 6 个人工审批点，不是倒退，而是一种务实。它承认了一个事实：AI 擅长「做」，但不擅长「判断」。把判断交给人，把执行交给机器——这才是内容生产的正确分工。
