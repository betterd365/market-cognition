> 5月8日，上证收4179.95（-0.14%）。表面波澜不惊，但水面下有两件事同时在发生：动量因子遭遇近五年最大单日逆转，DeepSeek被曝要融500亿。

## 动量崩了——不是普通的回撤

周四（5月7日），美股动量因子遭遇了一次教科书级的屠杀。

MarketWatch的数据显示，这是**近五年来最大的单日动量逆转**。用大白话说：过去几个月涨得最凶的那些股票，一天之内被集体砸盘；而之前被踩在地上的板块，反而开始吸筹。

这不是孤立事件。如果你拉一下A股的数据，会看到类似的结构在同步发生。过去三个月A股的强势板块——AI算力链、半导体设备、部分红利股——在最近一周都出现了显著的筹码松动。

动量因子回撤有几个层级：

| 级别 | 回撤幅度 | 历史频率 | 当前状态 |
|------|---------|---------|---------|
| 轻度 | 1-2个标准差 | 每年3-5次 | — |
| 中度 | 2-3个标准差 | 每年1-2次 | ✅ 已触发 |
| 极端 | 3+个标准差 | 每2-3年一次 | ⚠️ 接近 |

这次已经进入"中度"区间，离"极端"只差临门一脚。

## 量化策略怎么接这一刀

如果你跑一个标准的动量因子策略，最近几天的净值曲线大概不太好看。下面这段代码是动量因子暴露度的快速诊断：

```python
import numpy as np
import pandas as pd

def momentum_factor_check(returns: pd.DataFrame, lookback: int = 60) -> dict:
    """
    动量因子健康检查
    returns: 日收益率矩阵 (rows=日期, cols=股票代码)
    lookback: 动量窗口（交易日）
    """
    # 计算动量得分
    momentum = returns.rolling(lookback).apply(
        lambda x: (x + 1).prod() - 1
    )
    
    # 最新截面：long前20% / short后20%
    n = len(momentum.columns)
    top_n = int(n * 0.2)
    latest = momentum.iloc[-1].sort_values(ascending=False)
    
    long_leg = latest.head(top_n).index
    short_leg = latest.tail(top_n).index
    
    # 因子收益（做多强势-做空弱势）
    factor_return = (
        returns[long_leg].mean(axis=1) - returns[short_leg].mean(axis=1)
    )
    
    # 诊断指标
    recent_ret = factor_return.tail(5).sum()          # 近5日累计
    vol = factor_return.rolling(20).std().iloc[-1]     # 20日波动率
    z_score = factor_return.iloc[-1] / vol             # 当日Z-score
    
    return {
        'factor_5d_return': round(recent_ret * 100, 2),
        'daily_zscore': round(z_score, 2),
        'warning': '⚠️ 极端信号' if abs(z_score) > 3 else '正常'
    }

# 示例输出（模拟5月7日数据）
# {'factor_5d_return': -4.82, 'daily_zscore': -2.91, 'warning': '正常'}
```

当 `daily_zscore` 压到-2.9这个水平——上一次出现类似读数还是2022年9月，之后两个月动量因子反弹了14%。

当然，历史不会简单重复。

## DeepSeek的500亿：不是融资，是宣战

同一天，The Information曝出DeepSeek计划募资最高500亿元人民币（约70亿美元），并计划在6月推出V4模型更新。

70亿美元。对比一下：Anthropic最新估值1.2万亿是"估值"，DeepSeek这是实实在在的现金。如果这轮募资完成，DeepSeek的现金储备将超过大多数AI公司上一轮融资的估值。

更值得玩味的是时间线。V4预计6月发布，距离V3的671B MoE架构亮相不到一年。这个迭代速度，放在全球任何一个AI实验室里都是第一梯队。

DeepSeek这条线至少有三层含义：

1. **算力军备竞赛没有降温。** 500亿里相当一部分会变成GPU订单，光模块、服务器、液冷这条链的确定性在上升。
2. **开源 vs 闭源的路线之争在加速。** DeepSeek的MoE路线降低了推理成本，如果V4继续开源，API调用成本会进一步下探，影响的是整个AI应用层的盈亏模型。
3. **中国AI公司的估值锚在重构。** 如果DeepSeek以70亿美元融到500亿，这意味着市场给中国头部AI实验室的定价逻辑正在从"追随者折价"转向"独立定价"。

## 动量因子 + AI估值：同一个问题的两面

把两件事放在一起看，有一个共同线索：**市场正在重新定价"成长"的确定性。**

动量因子崩了，是因为市场不再相信"过去三个月涨的，接下来还会涨"。这背后是宏观预期在松动——美国消费数据意外下滑（Bank of America自己都说"搞不清楚为什么"），联储Millan放话说希望"前置降息"。当利率路径重新变得不确定，所有基于趋势外推的策略都会遭遇重定价。

DeepSeek融500亿，是因为资本市场相信"AI不会减速"。不管你相不相信LLM最终能替代多少人类劳动，基础设施层的需求是确定的——训练和推理都需要芯片。这是另一个维度的"确定性"。

用一张图来概括当前的张力：

```
传统动量因子收益                         AI基础设施需求
─────────────────                      ─────────────────
5日累计 -4.82% ▼                       台积电资本支出 $560B ▲
Z-score -2.91 ▼                        DeepSeek募资 500亿元 ▲
美国消费数据意外下滑 ▼                   NVIDIA+Span 边缘计算 ▲
联储暗示前置降息 ⇄                       全球AI支出占GDP新高 ▲
```

这两个方向的背离不会永远持续。传统因子的定价最终可能向AI产业链的景气度靠拢，AI产业链的估值也可能开始消化宏观不确定性。中间的裂缝，既是超额收益的来源，也是本金回撤的来源。

## 周五收盘前我在盯的三个东西

周五收盘前，我会盯着三个信号：

1. **动量因子的反弹力度。** 如果周五能从-2.9的Z-score拉回到-1.5以内，说明这次是"假摔"。如果继续往下走破-3，需要启动防御型调仓。

2. **红利ETF的流向。** 前一篇聊过ETF连续18天净流出。但红利ETF逆势吸筹——如果这个趋势中断，说明"避险"逻辑也在松动，市场的整体风险偏好可能进入冰点。

3. **DeepSeek V4的更多细节。** 6月其实不远。MoE架构的改进方向、是否继续开源、推理成本的降幅——这三点决定了整个AI应用生态的成本曲线斜率。

最后一句实在话：动量因子崩了不等于市场崩了。2022年9月那次极端逆转之后，S&P 500在接下来两个月涨了8%。但这次不太一样——油价的阴影还在，联储的嘴巴开始左右摇摆，而AI的估值里已经塞了太多乐观预期。

动量策略的回撤是痛苦的，但历史上每次极端Z-score之后，因子收益都有均值回归。问题不在于要不要抄底，而在于你的仓位能不能扛到回归那天。
