### 4. 项目名称：decolua/9router

**仓库地址：** https://github.com/decolua/9router

**一句话总结：** 一个本地网关，让你白嫖 40+ 个AI模型的API——Claude、GPT、Gemini、DeepSeek全免费，自动切换，永远不撞额度墙。

**核心痛点：**
- Claude Code / Codex / Cursor 等工具都要API Key，用多了就撞墙
- 9router 聚合了 40+ 个免费提供商（Kiro AI、OpenCode Free 等），本地跑一个网关（`npx 9router`），所有工具指向 `localhost:20128/v1` 就行
- 三级自动故障切换：主提供商挂了 → 自动切备选 → 再切第三梯队，用户无感
- RTK Token Saver：自动压缩上下文，节省 20-40% token 消耗

**举一反三（商业/应用价值）：**

🎯 **对我们集群的价值：**

1. **成本直接砍半** → 我们集群多Agent并行跑（财神盯盘、言师发帖、元师分析），API费用不低。接入9router可以大幅降低推理成本。

2. **集群高可用** → 目前依赖固定API提供商，如果挂了整个集群停摆。9router的多层fallback保证了服务的连续性。

3. **潜在风险：** 免费提供商的服务质量和隐私政策需关注。敏感数据（如持仓信息）不建议走免费通道。可以分两条线：非敏感任务走9router免费通道，敏感任务走正式API。
